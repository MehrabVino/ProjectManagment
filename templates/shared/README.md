# Shared Engineering Artifacts

Copy only the artifacts selected through [the engineering catalog](../../docs/engineering/README.md). These templates are intentionally tool-neutral.

| Artifact | Purpose |
| --- | --- |
| [ADR](ADR.md) | Preserve a consequential engineering decision and its trade-offs |
| [Modeling pack](MODELING.md) | Select the smallest useful domain/system diagram set |
| [Design-system contract](DESIGN_SYSTEM.md) | Define reusable interaction and visual rules without tying them to a UI framework |
| [Threat model](THREAT_MODEL.md) | Turn assets, trust boundaries, threats and mitigations into owned work |
