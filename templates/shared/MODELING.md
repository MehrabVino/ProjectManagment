# Modeling Pack

Choose diagrams for a reader's decision; do not create every diagram by default.

| Question | Smallest useful model |
| --- | --- |
| Who interacts with the system and what is outside it? | C4 context or use-case diagram |
| Which deployable/runnable parts exist? | C4 container/deployment diagram |
| Who owns a concept or data? | Domain model, bounded-context map, ERD |
| What happens over time? | Sequence, activity, or state-machine diagram |
| Which components may depend on which? | Component/dependency diagram |

Every diagram must name its audience, scope, assumptions, source of truth, and last review date.
